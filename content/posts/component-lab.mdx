Every post is plain MDX. This one exists to show the building blocks and the exact syntax for each, so a post never has to guess.

## Code

Fenced blocks get syntax highlighting in both themes and a copy button. A title and highlighted lines are optional.

```ts title="schedule.ts" {2}
export function nextRun(from: Date, everyHours: number) {
  return new Date(from.getTime() + everyHours * 3_600_000);
}
```

Inline code like `systemctl --user list-timers` is set in the mono face and nothing else is.

## Callouts

<Callout type="tip" title="Use sparingly">
One callout per section at most. If everything is highlighted, nothing is.
</Callout>

<Callout type="warn">
Anything that can lose data goes in a warning, before the command, not after.
</Callout>

## Terminal replay

Commands type out two characters at a time, like animation shot on twos. The whole transcript stays in the page for screen readers.
